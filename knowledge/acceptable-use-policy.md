# Cascadia Office of Technology — Acceptable Use Policy

Document ID: COT-SEC-003
Effective Date: January 1, 2026
Owner: Office of the Chief Information Security Officer

## Scope
This policy applies to all employees, contractors, and vendors using State of Cascadia information systems.

## Acceptable Use
- State systems are provided for state business. Incidental personal use is permitted if it does not interfere with duties or consume significant resources.

## Prohibited Activities
- Cryptocurrency mining on state hardware or cloud resources.
- Use of peer-to-peer file sharing or torrenting software.
- Circumventing security controls, including disabling endpoint protection.
- Storing state data on personal cloud accounts or removable media that is not state-issued and encrypted.

## Enforcement
- Suspected violations must be reported to the employee's manager and to the security team.
- Violations may result in loss of access and disciplinary action.
